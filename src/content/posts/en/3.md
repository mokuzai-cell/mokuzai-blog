---
title: "Taking Container Queries (@container) into Production"
description: "Styling based on parent element width instead of the viewport"
created: 2026-05-14
---

After relying on media queries (`@media`) for so long, we can finally take container queries (`@container`) for granted now.

Before, we could only handle responsive design based on "when the screen width is XX pixels." But thanks to container queries, we can now say, "when the parent element of this card component is XX pixels wide."

This is going to take component reusability to a whole new level. It's so satisfying that whether you drop a component into a sidebar or the main content area, it just automatically shrinks or expands beautifully.
